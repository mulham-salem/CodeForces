# Problem 153A – A + B

## Overview
This problem is a simple arithmetic task.  
You are given two integers **A** and **B**, and you need to compute their sum.

The goal is to output the result of:

A + B

The output must not contain leading zeros.

---

## Input
- The input consists of two lines:
  - First line: integer A  
  - Second line: integer B  

Constraints:
- 1 ≤ A, B ≤ 10^5

---

## Output
Print a single integer representing the sum of A and B.

---

## Examples

### Example 1
**Input**

12 3

**Output**

15

**Explanation**  
12 + 3 = 15

---

### Example 2
**Input**

100 5

**Output**

105

**Explanation**  
100 + 5 = 105

---

## Key Idea
- Read two integers
- Compute their sum
- Print the result directly
- No extra formatting is required

---

## Solution Idea (Pseudocode)

read A read B print A + B
